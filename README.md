# Дипломна работа: Автотесты для сайта "Читай-город"

## Описание проекта
Автоматизированное тестирование веб-сайта и API интернет-магазина "Читай-город".

## Структура проекта
- `tests/` - автотесты (UI и API)
- `pages/` - Page Object модели
- `config/` - конфигурационные файлы
- `utils/` - вспомогательные функции

## Запуск тестов

### Все тесты

pytest
